Month Finder

This program takes a number (1-12) and prints the corresponding month.

Mapping:
1  -> January
2  -> February
3  -> March
4  -> April
5  -> May
6  -> June
7  -> July
8  -> August
9  -> September
10 -> October
11 -> November
12 -> December

If the number is not in 1-12, it prints 'Invalid month.'

How it works:
- The program asks the user to enter a number representing the month.
- It uses a series of if-else statements to determine the correct month.
- If the number is outside the range 1-12, the program prints "Invalid month."
- The result is printed on the screen.
