# 🧩 C++ Problem Solving – Level 1

Welcome to the **C++ Porblem Solving Level 1** repository! 🎯

This repository contains my **first collection of problem-solving exercises in C++**, all solved by me. The goal is to build a strong foundation in programming logic, clear code, and problem-solving with C++.

---

## 📚 About This Repository

* The repository contains **50 folders**.
* Each folder contains **one problem only**.
* Every problem is different — no repeated ideas.
* All solutions are written **by me from scratch**.
* This was my **first real project** in programming.
* These 50 problems are the **easiest / beginner level** that I started with.

---

## 🎯 What This Repository Demonstrates

* Beginner-level programming thinking.
* Problem analysis and simple solution design.
* Writing clean and straightforward code without unnecessary complexity.
* Organizing each problem in its own folder for clarity.

---

## 📁 Folder Structure

Each folder follows this structure:

```
Problem-XX/
├── main.cpp
└── problem-description.txt (optional)
```

This repository is a solid starting point for learning problem solving using only the most basic C++ concepts such as if statements, loops (for, while, do‑while), and simple logic.
