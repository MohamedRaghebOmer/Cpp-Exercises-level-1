Problem Title: Rectangle Area Using Pythagoras
Level: Beginner – Functions & Math

Description:
This program calculates the area of a rectangle using a function
and the Pythagorean theorem. It takes two values (a and d), and
computes the area with the formula:

    Area = a * sqrt(d^2 - a^2)

Input:
- In this example, the values are hardcoded (a = 5, d = 40).

Output:
- Prints the calculated area of the rectangle.

Logic Used:
- Defines a function Procedure_To_Calculate_Rectangle_Area(float a, float d).
- Uses pow() and sqrt() from <cmath> to calculate the area.
- Prints the result using cout.

Key Concepts:
- Functions with parameters
- Basic arithmetic and mathematical functions
- sqrt() and pow() from <cmath>
- Console output (cout)
