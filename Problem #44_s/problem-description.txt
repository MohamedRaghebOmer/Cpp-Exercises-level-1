Day of the Week Finder

This program takes a number (1-7) and prints the corresponding day of the week.

Mapping:
1 -> Saturday
2 -> Sunday
3 -> Monday
4 -> Tuesday
5 -> Wednesday
6 -> Thursday
7 -> Friday

If the number is not in 1-7, it prints 'Invalid day.'

How it works:
- The program asks the user to enter a number representing the day of the week.
- It uses a switch statement to determine the correct day.
- If the number is outside the range 1-7, the program prints "Invalid day."
- The result is printed on the screen.
