Problem Title: Circle Area Using Advanced Formula
Level: Beginner – Math & Input/Output

Description:
This program calculates the area of a circle using two user inputs (a and b)
and applies the formula:

    Area = π * (b^2 / 4) * (2a - b) / (2a + b)

Input:
- Two floating-point numbers: a and b, entered by the user.

Output:
- Prints the calculated area of the circle.

Logic Used:
- Reads values a and b using cin.
- Applies the formula step by step using basic arithmetic operations.
- Prints the result using cout.

Key Concepts:
- Basic arithmetic
- User input/output
- Floating-point calculations
- Using parentheses to control order of operations
