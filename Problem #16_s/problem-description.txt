Problem Title: Rectangle Area from Two Inputs Using Pythagoras
Level: Beginner – Math & Input/Output

Description:
This program calculates the area of a rectangle based on user input
for two values (a and d) using the formula:

    Area = a * sqrt(d^2 - a^2)

It demonstrates reading input from the user, performing mathematical
calculations, and printing the result.

Input:
- Two integers: a and d entered by the user.

Output:
- Prints the calculated area.

Logic Used:
- Uses cin to read input values.
- Uses pow() and sqrt() from <cmath> to calculate the area.
- Prints the result using cout.

Key Concepts:
- User input/output
- Functions from <cmath> (pow, sqrt)
- Basic arithmetic
